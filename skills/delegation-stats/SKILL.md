# Delegation Stats

Сборщик читает локальные Codex JSONL и необязательный индекс `state_5.sqlite` без записи в источники. Использует только Python 3.11+ и стандартную библиотеку. Не запускает агентов, серверы или фоновые процессы.

## Обновление

Запускай `scripts/collect.py` из каталога этого навыка. Обычное окно — последние 7 дней по времени событий; повторный запуск читает добавленные полные строки. Для согласованного vault:

```sh
python3 "${CODEX_HOME:-$HOME/.codex}/skills/delegation-stats/scripts/collect.py" \
  --vault "$HOME/Documents/Obsidian/Codex" --api-equivalent
```

Путь vault в примере замени на уже согласованный. Без `--vault` обновляются только приватные локальные агрегаты. Не выбирай чужой vault по догадке. Поддерживаются `--codex-home`, `--state-dir`, `--vault`, `--days` и `--root-thread` (корневой идентификатор вместе с потомками). Параметр `--api-equivalent` включает отдельный условный API-сценарий; это не фактические списания.

Приватное состояние: `${XDG_STATE_HOME:-$HOME/.local/state}/codex-dialogue-kit/telemetry`. JSON/SQLite имеют права 600, каталог — 700. Сборщик управляет только своим подкаталогом `Телеметрия/Делегирование` выбранного vault и только заметками со своим маркером. Остальные заметки сохраняются. Не добавляй состояние или реальные заметки в git. Данные остаются локальными; обычная синхронизация самого vault определяется настройками пользователя.

## Как читать результат

- Расход — сумма уникальных response-level usage. Накопительные totals, fork baseline и compaction snapshots не суммируются. Конфликтующие записи исключаются и отражаются в покрытии.
- Cached входит в input, reasoning входит в output. Сумма расхода — input + output. Неизвестные поля остаются неизвестными; суммы показывают только известную часть.
- Runtime-модель взята из `turn_context`, это подтверждение конфигурации, а не backend-квитанция. Запрошенная модель берётся только из однозначно сопоставленного вызова spawn. Модель в изменяемом индексе потока не приписывается истории.
- Сумма длительностей ходов разных агентов может перекрываться и не равна wall-clock группы. `task_complete` не доказывает бизнес-успех; незавершённый ход обозначается «no observed completion».
- Фактическая стоимость и режим оплаты неизвестны. API-сценарий использует только точные известные имена моделей, известный cached input, нулевой cache-write и input ≤128 000; этот лимит — условие сценария. Исключённые ответы видны отдельно. Тарифная дата и ссылки находятся в дашборде. Перед новой тарифной трактовкой проверь первичный источник; не расширяй таблицу по догадке.

В дашборде видны все агрегаты выбранного окна и до 50 последних групп со ссылками родитель → ребёнок. В SQLite сохраняется нормализованная история; исходные тексты запросов, ответы, инструменты с произвольными аргументами и секреты не копируются. Доступны только allowlist-метаданные.

Если результат неполон, сообщи конкретные показатели покрытия: legacy-only потоки, неизвестные модели/поля, исключённые конфликты, незавершённые строки, ошибки чтения. Не выдавай зелёный запуск CLI за полноту учёта. Обновление статистики не даёт разрешения менять навыки или публиковать данные.
