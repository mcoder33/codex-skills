# Сценарии приёмки

Выбирай только сценарии затронутой логики. Это обезличенные входы и ожидаемые результаты, а не заявление о выполнении. Исторические данные используй только на чтение; синтетические случаи — локально. Изменённые запросы и transformations проверяй отдельно на реальном datasource и в render.

| Сценарий | Вход | Ожидаемый результат |
| --- | --- | --- |
| Последний снимок против экстремума | Один слот: 10:00 WAL=80, active=0; 10:01 WAL=20, active=1 | Текущее состояние: 20 и 1 с timestamp 10:01. 80 и 0 допустимы только как явно подписанные экстремумы периода |
| Новый ошибочный снимок | 10:00 status=ok, value=7; 10:01 status=error без value | Ошибка 10:01 и неизвестное значение; старое 7 не выглядит актуальным |
| Неполное покрытие | Ожидаются службы A/B/C; три последних документа относятся к A/A/B | C отмечена как отсутствующая/устаревшая. Лимит 3 не считается доказательством покрытия трёх служб |
| Задержка доставки | Измерение 10:00 поступило в индекс 10:15; сейчас 10:16 | Возраст состояния считается от измерения, доставка показывается отдельно; сравнение с допустимой свежестью использует контракт сбора |
| Пустые алерты | Алертов нет; сначала все ожидаемые объекты свежие, затем один исчезает | В первом случае допустимо «активных алертов нет»; во втором unknown/stale даже при живом общем heartbeat |
| Восстановление | 10:00 error, 10:01 ok с полными данными | Текущая карточка показывает ok 10:01; историческая ошибка остаётся в истории, а не навечно в текущем max |
| Идентичность | Один объект меняет status и wal_status | Одна текущая строка на устойчивый ключ; изменяемые поля не создают дубликаты |
| Область фильтров | Выбор A, A+B, All; общая дисковая панель | Тематические панели отражают выбранные объекты; общий диск явно подписан как общий. Фильтр службы не обещает фильтрацию всех баз |
| Интерполяция | Допустимое имя с дефисом, пробелом или спецсимволом языка запроса | Синтаксис валиден; совпадает нужный объект, без непреднамеренного расширения выборки |
| Окно панели | Карточка «5 минут»: относительные 6 часов и фиксированный исторический диапазон | Фактические from/to проверены; подпись соответствует поведению override, исторический результат не выдаётся за «сейчас» |
| Нет работ COPY | Свежий завершённый перенос без активных COPY rows | Объяснённое отсутствие активного копирования; не сбой коллектора и не доказательство готовности cutover |
| Отставание и простой | Свежие позиции не меняются: сначала backlog=0, затем backlog>0 | Первый случай сам по себе не зависание; второй требует проверки продвижения и контракта алерта |
| Сброс | Счётчик/позиция падает после перезапуска | Нет фиктивной отрицательной скорости или spike; reset отмечен/обработан по контракту |
| Читаемость | Обычная ширина экрана, длинный title и несколько серий | Ключевые подписи различимы, важные колонки и легенды доступны; предупреждение выделяется на фоне нормальных значений |

При обновлении самого навыка разберите применимые сценарии и укажите уровень доказательства. Проверка структуры Markdown не доказывает, что другой агент выберет правильный запрос; такой вывод требует отдельного поведенческого прогона при разрешённой делегации.
