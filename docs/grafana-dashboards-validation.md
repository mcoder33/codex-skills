# Проверки grafana-dashboards

Обновление 2026-10-16 усиливает установленный instruction-only навык: текущие снимки и исторические экстремумы, время измерения и доставки, область фильтров, понятность цветов и подписей. Добавлены условная справка PostgreSQL и 14 сценариев приёмки. В публичную версию не включены реальные dashboard JSON, адреса проектов, имена служб или данные источников.

Самопроверка по сценариям выявляет разные уровни требований:

- пять локальных синтетических инвариантов вычислены Python: последний согласованный снимок отличается от max/min, ошибка без value вытесняет старое значение, лимит документов не гарантирует покрытие, возраст измерения отличается от возраста доставки, восстановление вытесняет прежнюю ошибку;
- остальные сценарии разобраны на соответствие инструкциям: идентичность, фильтры, интерполяция, временные окна, завершённый COPY, простой и backlog, reset, читаемость;
- quick_validate, структура навыков и локальные ссылки проверяются штатными валидаторами; регрессии — существующим unittest-набором репозитория. Число выполненных тестов и CI фиксируются в PR;
- первичные определения позиций и слотов сверены с документацией PostgreSQL; особенность абсолютных временных диапазонов — с документацией Grafana, ссылки доступны в references.

Первый локальный запуск системным Python 3.9 остановился на отсутствующих зависимостях и tomllib. Повторный запуск выполняется в отдельном окружении современного Python с закреплёнными зависимостями репозитория.

Синтетические инварианты подтверждают ожидаемые значения примеров, а не работу Grafana transformations. Независимый прогон навыка другой моделью не выполнялся. Новая редакция не применялась к живому дашборду, поэтому исправление его отображения и бизнес-результат не заявляются. Внешняя публикация — отдельный Draft PR; установленная локальная копия сверяется с файлами публикации.
