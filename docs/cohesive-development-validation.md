# Исторические проверки cohesive-development

Этот отчёт относится к прежнему навыку, заменённому [go-development](../skills/go-development/SKILL.md). Проверки старых версий не доказывают поведение новой.

## Версия 0.2.0 — путь чтения и совместная работа

Дата: 2026-10-17. Изменены инструкции и UI-описание; исполняемые инструменты,
глобальные настройки и профили агентов не менялись.

В изолированном Python 3.12 окружении с зависимостями репозитория прошли
quick_validate навыка, проверки структуры и локальных ссылок всего набора,
96 существующих unit-тестов и git diff --check. UI YAML разобран: сохранено
автоматическое обнаружение, default_prompt содержит имя навыка. Python-пример
проверен синтаксически; он иллюстрирует чтение, не является рабочим приложением.
Проверка переносимости изменённых материалов не обнаружила личных путей,
идентификаторов сессий или ссылок на приватные проекты.

Первый запуск через системный Python не загрузил PyYAML/markdown-it-py.
После установки зафиксированных CI-зависимостей в отдельное окружение проверки
прошли; глобальные Python-пакеты не устанавливались.

Проведена авторская проверка инструкций по следующим случаям:

| Случай | Проверенное решение в тексте навыка |
|---|---|
| Чтение кода как графа | Функции/типы/файлы и переход к определению; отдельный UI не требуется |
| Красивый фасад, смешанные обязанности внутри | Проверка дочерних операций и конкретного места потери смысла |
| Имя обещает доставку, реализация только ставит в очередь | Ответ читателя сверяется с фактическим контрактом |
| Обычный багфикс или запрет делегации | Соразмерная самопроверка; полный состав агентов не обязателен |
| Разные файлы с общим правилом | Назначенный владелец контракта, согласование интерфейса до параллельных правок |
| Положительная оценка чтения и регрессия поведения | Регрессия блокирует приёмку; голосование не заменяет доказательство |
| Изменение кандидата после ревью | Перепроверка затронутого пути на новой версии |
| Читатель получил историю автора | Ограничение независимости явно обозначается |

Это самопроверка содержания, а не независимый запуск модели по обновлённому
протоколу. Живой рой и чтение людьми в этой итерации не проверялись. Прежние
пилоты ниже сохранены как свидетельства версии 0.1.0 и не приписываются новой.

## Версия 0.1.0

Дата: 2026-10-16. Это проверка локального instruction-only навыка перед
публикацией, а не исследование эффективности разработки людьми.

## Структура и упаковка

- Штатный quick_validate прошёл для всех семи навыков набора.
- UI metadata и allow_implicit_invocation=true разобраны как YAML.
- Относительные ссылки нового навыка существуют.
- Установленные пять файлов навыка совпадают с переносимой копией пакета.
- Новые файлы проверены на локальные личные пути, ссылки частного проекта
  и идентификаторы сессий. Рабочие журналы и полные отчёты пилота не включены.
- 89 существующих unit-тестов репозитория прошли. Они проверяют регрессии
  существующих инструментов, а не сами по себе качество нового навыка.

## Реалистичные поведенческие пробы

Три независимых исполнителя Sol/medium получили разные синтетические
Python-проекты, текст запроса, навык и доступ только к своему каталогу.
Исходное приложение и конфигурация пользователя не менялись. Исполнители
не получали ожидаемой архитектуры или вердикта. Отдельный reviewer читал
фактические результаты и проверял соответствие запросам.

| Проба | Наблюдаемый результат |
|---|---|
| Рефакторинг подготовки отправления | Сценарий и завершённые helpers выделены; 432 заранее сохранённых наблюдения результата/ошибки, emit trace и неизменности входа совпали после правки |
| Улучшить всё миниприложение | Просмотрены 3/3 модуля и README; повторное правило SKU передано существующему владельцу, для двух модулей сохранение кода обосновано; карта покрытия не скрывает остаток |
| Исправить подпись кнопки | Изменена одна строка, итоговый файл сравнен точно; дополнительных тестов, отчётов и архитектурной уборки нет |
| Отрицательный контроль «переведи фразу» | Исполнитель верно признал навык неприменимым; это проверка решения по запросу, а не измерение автоматического выбора harness |

Исполнитель первого случая дополнительно сообщил о 64 собственных
characterization-прогонах, включая порядок чтения и callback failures.
Основной агент отдельно выполнил 432 сравнения из своего набора. Во втором
случае 5 characterization tests прошли до/после по отчёту исполнителя;
reviewer самостоятельно повторил 5/5 на кандидате.

Reviewer принял три результата. Спорный участок первого примера — helper
сборки JSON с правилами полей. Он принят как цельный adapter для показанного
контекста; это не универсальное разрешение прятать доменные политики в
serializer. Обязательный запрет совместного mapping/encoding не добавлялся.

## Что эти проверки не доказывают

Реальное время/точность чтения людьми, применение в больших проектах и
статистическое преимущество над исходными инструкциями не измерялись.
Нет отдельного baseline-прогона модели без навыка, поэтому причинный эффект
навыка не установлен. Изолированные пробы подтверждают несколько выбранных
решений и отсутствие наблюдаемых регрессий в них.

Глобальный AGENTS-блок обеспечивает явную инструкцию применять навык при
разработке; implicit invocation оставлено включённым. В текущих пробах навык
указан явно. Автоматическое обнаружение новым runtime и срабатывание на
произвольном пользовательском запросе этими пробами не доказаны. После
установки следует проверить загрузку инструкций в используемом клиенте.
