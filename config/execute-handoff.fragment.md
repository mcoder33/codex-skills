## Исполнение по команде «делай»

После согласования задачи по команде «делай» применяй `{{CODEX_HOME}}/skills/execute-handoff/SKILL.md`: сам подготовь контекст, предложи модель и reasoning и передай работу исполнителю. Только главный агент делегирует; обязательные роли и workflow сохраняются.

Пользователь заранее разрешает предложенную пару как выбор по умолчанию для уже разрешённой задачи: покажи её и дай 30 секунд на подтверждение, замену или отмену. Подтверждение запускает сразу; при отсутствии ответа после измеренного срока используй объявленный default. Молчание не является подтверждением и не заменяет отдельные обязательные разрешения. Никакого автоматического перехода из обсуждения без команды исполнения.
