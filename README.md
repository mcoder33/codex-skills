# Codex Skills

Набор навыков для работы с Codex: разобраться в задаче, проверить план, написать связный код, настроить дашборд и сохранить ход обсуждения. Основной язык инструкций — русский.

Навык — каталог с `SKILL.md` и, при необходимости, справочниками и скриптами. Вы выбираете нужные навыки и вызываете их в запросе. Устанавливать весь набор, подключать Obsidian или настраивать подагентов для первого знакомства не нужно.

## С чего начать

1. Выберите навык в таблице ниже. Для первого запуска подойдёт `adaptive-dialogue`: ему не нужны дополнительные инструменты.
2. [Установите выбранный навык](docs/installation.md) и откройте новый сеанс Codex.
3. Введите запрос с именем навыка:

   ```text
   $adaptive-dialogue Объясняй сначала результат, затем основания.
   Если я прошу кратко, сохраняй важные ограничения.
   ```

Для работы с Go-кодом попробуйте `$go-development`, для обсуждения неясной задачи — `$dialogue-explore`. [Примеры запросов и ожидаемых результатов](docs/usage.md) помогут проверить первый запуск.

## Какой навык выбрать

| Ваша задача | Навык | Что должно получиться |
| --- | --- | --- |
| Понятно изложить объяснение, исследование или план | [clear-communication](skills/clear-communication/SKILL.md) | Вывод с основаниями, корректные числа и видимые ограничения |
| Настроить тон, подробность и темп общения | [adaptive-dialogue](skills/adaptive-dialogue/SKILL.md) | Ответы учитывают явные предпочтения и поправки |
| Разобраться в неясной проблеме вместе | [dialogue-explore](skills/dialogue-explore/SKILL.md) | Последовательное обсуждение, решения и открытые вопросы в карте |
| Проверить уже предложенный план | [dialogue-validate](skills/dialogue-validate/SKILL.md) | Проверенные основания, слабые места и необходимые проверки |
| Оценить готовность инженерного решения | [nasa](skills/nasa/SKILL.md) | Связь требований, решений, допущений и доказательств |
| Разработать или проверить Go-код | [go-development](skills/go-development/SKILL.md) | Законченные операции, читаемые пути по коду, владение данными и проверка поведения |
| Создать или улучшить дашборд Grafana | [grafana-dashboards](skills/grafana-dashboards/SKILL.md) | Обоснованные метрики, запросы, фильтры и проверка отображения |
| Распределить работу между моделями | [model-router](skills/model-router/SKILL.md) | Выбранный исполнитель с ограниченным контрактом |
| Посмотреть статистику делегирования | [delegation-stats](skills/delegation-stats/SKILL.md) | Локальный Markdown-отчёт по событиям Codex |
| Улучшать инструкции по завершённым сессиям | [session-retrospective](skills/session-retrospective/SKILL.md) | Проверенная небольшая правка двух dialogue-навыков либо обоснованный отказ от изменения |

В каталоге 10 навыков. Каталог описывает файлы этой ветки. Состав релиза может отличаться: для воспроизводимой установки выбирайте [тег релиза](https://github.com/mcoder33/codex-skills/releases) и читайте документацию на этом теге.

## Установка и использование

- **[Установка](docs/installation.md):** один навык, пара dialogue, Obsidian, профили моделей, обновление и откат.
- **[Практические примеры](docs/usage.md):** что написать, какой результат проверить и как продолжить работу.
- **[Устранение проблем](docs/installation.md#если-что-то-не-работает):** навык не виден, карта не сохраняется, модель недоступна.
- **[Внесение изменений](CONTRIBUTING.md):** структура навыка, локальные проверки и PR.

## Дополнительные возможности

Подключайте их, когда базовый сценарий уже работает.

| Возможность | Для чего | Руководство |
| --- | --- | --- |
| Карта Obsidian | Хранить обсуждения, решения и вопросы в связанных Markdown-заметках | [Установка карты](docs/installation.md#карта-обсуждений-в-obsidian), [вымышленный пример](vault-template/Карта%20обсуждений.md) |
| Профили подагентов | Настроить резервных исполнителей для `model-router` | [Настройка профилей](docs/installation.md#модели-и-подагенты) |
| Статистика | Разобрать токены, длительности и связи агентов по локальным событиям | [Телеметрия](docs/telemetry.md) |
| Ретроспектива | Проверять небольшие изменения `dialogue-explore` и `dialogue-validate` | [Ретроспектива](docs/retrospective.md) |
| Runtime и hooks | Восстанавливать точку применения навыка после сокращения контекста | [Runtime](docs/skill-runtime.md), [совместимость hooks](docs/hooks-compatibility.md) |

Переносимое [дополнение к оценке задач](docs/skill-patches/estimate-unresolved-forks.md) останавливает передачу задачи при нерешённом выборе. Оно встраивается в существующий навык оценки и не является одиннадцатым навыком набора.

[Состав интеграционного кандидата и проверки](docs/prepared-skills-integration.md) описывают изменения относительно v0.4.1; это ещё не опубликованный релиз.

Runtime не нужен для обычного вызова навыка. Ретроспектива требует отдельного разрешения на изменения; установка не создаёт расписание. Статистика не показывает фактические списания за использование моделей.

## Что лежит в репозитории

```text
skills/          Навыки: SKILL.md, справочники, скрипты и UI-метаданные
agents/          Четыре резервных профиля подагентов
config/          Фрагменты инструкций и конфигурации для ручного слияния
vault-template/  Вымышленный пример связанных заметок Obsidian
runtime/         Необязательное сохранение состояния навыков
scripts/         Установщик runtime и проверки репозитория
tests/           Автоматические тесты
docs/            Руководства, технические контракты и отчёты проверок
```

## Границы и лицензия

Навыки задают способ работы, но не предоставляют доступ к сервисам и не расширяют разрешения на публикацию, production или сообщения другим людям. Поддержка моделей и подагентов зависит от вашего клиента и аккаунта. Профили агентов — инструкции, а не техническая песочница.

Сохранённый план не доказывает его работоспособность, а успешный тест файлов не доказывает пользу метода во всех задачах. Личные журналы, настройки аккаунта, секреты и реальные карты обсуждений храните вне этого репозитория.

Лицензия пока не выбрана, файла `LICENSE` нет. Публичность репозитория сама по себе не предоставляет отдельную лицензию на использование и распространение.
