# Проверка протокола

Версии: dialogue-explore 0.1.0, dialogue-validate 0.1.0, model-router 0.1.
Пример темы: [[Обсуждения/Пилот учебной встречи]].

Предлагаемые критерии: ответ пользователя действительно меняет следующий шаг; предложение не становится решением без согласия; после паузы по карте можно восстановить вопрос и основания; проверка плана выявляет существенное неизвестное без утверждения, что мысленный сценарий доказал результат.

Результат: ещё не проверено. При пилоте записать конкретный эпизод, влияние, выбранную модель/effort и подтверждение рантайма, если оно доступно. Предложения улучшений держать отдельно от принятых правил.
